Palindrome Checker

Description

The Palindrome Checker is a simple Python project that checks whether a word or sentence reads the same forward and backward. It ignores capitalization and unnecessary spaces before comparing the text.

Objective

To practice string manipulation, string slicing, and comparison logic in Python.

Features

- Accepts a word or sentence from the user.
- Converts the input to lowercase.
- Removes spaces.
- Reverses the string using slicing.
- Displays whether the input is a palindrome.

Technologies Used

- Python 3

How to Run

1. Save the program as "palindrome_checker.py".
2. Open the file in Python IDLE or VS Code.
3. Run the program.
4. Enter a word or sentence.
5. Check the result displayed on the screen.

Example

Input: Madam

Output: It is a palindrome!

Conclusion

This project demonstrates how Python string methods and slicing can be used to identify palindromes efficiently.
